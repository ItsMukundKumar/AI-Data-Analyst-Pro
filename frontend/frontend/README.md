# AI Data Analyst Pro – Frontend

1. Start the backend: `python main.py` (serves http://127.0.0.1:8000).
2. From this `frontend/` folder run: `python -m http.server 5500`
3. Open http://127.0.0.1:5500 (CORS is already allowed by your backend).

Change the backend URL in `js/config.js`. Internet access is needed for Plotly, Lucide and Google Fonts CDNs.
